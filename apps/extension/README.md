# apps/extension — Extensión de navegador

**Propósito:** Extensión de navegador para auto-tracking. Detecta el final de un episodio en plataformas de streaming y registra el progreso automáticamente llamando al BFF.

**Dueño:** Frontend team

## Stack

- TypeScript
- WebExtensions API

## Arranque local

```bash
# Desde la raíz del monorepo
pnpm install
pnpm --filter @animetracker/extension build
```

Ver el README raíz para instrucciones completas del entorno local.
